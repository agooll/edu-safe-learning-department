# 专家榜评分映射

| 评分维度 | 设计证据 |
|---|---|
| 运行稳定性与鲁棒性 | 纯 Python 标准库脚本；输入、交接、学习阶段、插问栈与 ZIP 均可验证；失败关闭；返修和分支深度有上限 |
| 创新性和应用价值 | 部门式多 Skill 编排；四角色工作流；可中断恢复学习；结课笔记带完整性可验证时间记录；艾宾浩斯七点绝对检查；到期后由用户选择复习或跳过；跳过不伪装成掌握；质量门和安全门分离 |
| 结果质量 | 业务专职 Skill、独立质量审计、依据与假设披露、可执行下一步 |
| 技术设计与场景编排 | 角色与任务双轴路由、会话分类、主线/插问分支、学习阶段监控、输入预检、单主责路由、专业处理、时间戳凭据、长期复习调度、质量审计、最终门禁、人工升级 |
| 工程规范与文档 | 标准 SKILL.md、引用式渐进加载、示例、测试与打包检查 |
| 安全合规 | 数据最小化、去标识化、反作弊、提示注入防护、高影响决定人工复核 |

演示时优先展示六组场景：四角色分流、普通学习主线推进、途中插问后准确恢复、结课笔记及篡改检测、20 分钟检查点到期后选择复习或跳过、实时考试代答被阻断或正式评分被标记为人工复核。
