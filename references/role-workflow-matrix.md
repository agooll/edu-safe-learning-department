# 角色线路与强制步骤矩阵

## 强制级别

| 级别 | 含义 |
|---|---|
| 全局强制 | 所有角色、所有实质性输出都必须执行，不能关闭 |
| 角色强制 | 进入某角色线路后必须执行 |
| 条件强制 | 满足特定条件时必须执行 |
| 可选 | 由任务需要或用户选择决定，不影响其他强制门禁 |

## 全局强制步骤

以下步骤对学生、教师、监护人和教育管理者全部强制：

1. 输入生成前安全预检；
2. 角色识别和权限边界确认；
3. 角色加任务双轴路由；
4. 每轮只有一个主责业务 Skill；
5. 业务输出使用机器可读交接；
6. 独立质量审校；
7. 最终安全门禁；
8. 异常、缺失、冲突和风险不明时失败关闭；
9. 对外只保留一个下一动作；
10. 不自动写入成绩、处分、录取或学生档案系统。

## 学生线路

目标：让学习者真正完成学习，而不只是得到答案。

```text
身份与目标确认
→ 初始化学习状态、笔记策略和提醒策略
→ 基线诊断
→ 知识讲解
→ 引导练习
→ 依据标准反馈
→ 针对性重试
→ 迁移验证
→ 延迟复习
→ 完成判定
→ 笔记预览或落盘
→ 时间戳校验、七项提醒清单与长期复习调度
→ 已授权时注册 AstronClaw 定时任务；否则交互检查
→ 用户选择跳过或按复习结果回流
```

| 组件或步骤 | 级别 | 启用条件 |
|---|---|---|
| `edu-learning-stage-monitor` | 角色强制 | 学生持续学习每一轮开始和结束 |
| `edu-context-resume` 消息分类 | 角色强制 | 学生持续学习每一条消息 |
| 主线快照与 `push` | 条件强制 | 检测到明确插问 |
| 分支总结与 `pop` | 条件强制 | 学习者说回到主线或插问结束 |
| `edu-personalized-planner` | 阶段强制 | 目标设置；中途调整计划时可再次启用 |
| `edu-learning-diagnostician` | 阶段强制 | 基线诊断；反馈暴露新错因时条件启用 |
| `edu-teaching-designer` | 阶段强制 | 知识讲解、引导练习、补救和延迟复习 |
| `edu-assessment-reviewer` | 阶段强制 | 练习反馈与迁移验证，必须有明确判定标准 |
| `edu-learning-note-capture` | 完成强制 | 阶段进入 `completed` 后必须生成笔记候选 |
| 笔记实际写入 | 条件强制 | `on-completion` 或 `ask` 后明确确认；`disabled` 不写 |
| 笔记时间戳凭据 | 落盘强制 | 笔记写入时必须生成 UTC 时间、笔记 SHA-256、凭据 SHA-256和审计事件 |
| 七项提醒清单 | 落盘强制 | 与七个绝对检查点同锚生成；清单不等于平台任务已注册 |
| AstronClaw 定时任务 | 用户选择 + 条件启用 | 仅 `reminder_policy: scheduled` 且平台能力可用时创建；成功回执必须绑定任务 ID |
| 交互时检查降级 | 条件强制 | 未授权、无定时工具或注册失败时，每次进入学生线路运行 `due` 并披露降级 |
| `edu-spaced-review-scheduler` 到期检查 | 角色强制 | 学生后续进入系统且存在复习计划；每次先校验时间戳，未到期不打断主线 |
| 七个绝对检查点 | 落盘强制 | 从笔记时间严格计算 20 分钟、1 小时、9 小时、1 天、2 天、6 天、31 天 |
| 到期选择 | 到期强制 | 必须展示“立即复习”和“跳过本次”，不得替用户默认选择 |
| 立即复习 | 用户选择 | 按检查点执行主动检索、重点回顾、迁移或月度保持检查；通过需要证据 |
| 跳过本次 | 用户选择 | 无需掌握证据，但必须留痕并标记 `mastery_claimed: false` |
| 遗忘回流 | 条件强制 | 复习暴露缺口时保留当前检查点并回流诊断/补救 |
| 外部资源检索 | 可选 | 用户要求最新资料或本地材料不足，并保留来源 |

学生不能仅凭“我懂了”跳过结课前的练习、迁移验证或延迟复习。结课后的保持性检查点允许用户自主跳过，但跳过不等于掌握、不得成为正式证据。插问期间冻结主线，插问答案仍经过全局安全闭环。

## 教师线路

目标：减少备课和评阅负担，同时保留教师专业责任。

| 任务 | 必须启用 | 条件启用 | 可选 |
|---|---|---|---|
| 教案、课件、试题 | 路由、教学设计、质量审校、最终门禁 | 最新事实检索、教材来源核验 | 分层练习、不同课时版本 |
| 作业或作文评阅 | 路由、评阅、评分标准检查、质量审校、最终门禁 | 正式成绩人工复核 | 学情诊断、补救练习 |
| 班级学情分析 | 路由、诊断、数据最小化、质量审校、最终门禁 | 小样本和个体数据人工复核 | 个性化教学计划 |

教师线路默认不启用学生阶段状态、插问栈和学生笔记归档。教师明确进入“陪学生学习”模式时，创建独立学生会话后才启用学生线路。

## 监护人线路

目标：提供家庭学习支持，而不是替代教师评分或获取不必要学生信息。

| 步骤 | 级别 | 规则 |
|---|---|---|
| 角色与授权确认 | 角色强制 | 查看具体学生记录需要 `consent.guardian_authorized: true` |
| 隐私最小化 | 角色强制 | 只展示当前目标、阶段、摘要和建议，不展示原始作答与其他学生数据 |
| 家庭支持建议 | 角色强制 | 路由个性化规划，输出可执行且不过度干预的建议 |
| 医学、心理或能力标签 | 禁止自动化 | 转具备资质的专业人员 |
| 学生笔记查看 | 条件强制 | 仅在学习者授权且笔记已经去标识化时 |
| 正式评分和处分建议 | 禁止自动化 | 转教师或学校人工流程 |

## 教育管理者线路

目标：支持聚合分析和治理决策，不让模型自动做高影响决定。

| 步骤 | 级别 | 规则 |
|---|---|---|
| 管理权限确认 | 角色强制 | `data_scope: individual` 的个体记录需要 `consent.admin_authorized: true` |
| 聚合与去标识化 | 角色强制 | `data_scope: aggregate` 只处理班级或群体统计摘要，不沿用个体权限 |
| 审计记录 | 角色强制 | 记录请求 ID、决策和规则代码，不记录原始学生文本 |
| 高影响决定人工复核 | 条件强制 | 分班、录取、处分、资源剥夺等永远不自动执行 |
| 教学资源或制度建议 | 可选 | 明确依据、假设和适用范围 |
| 学生持续学习状态 | 默认关闭 | 管理任务不创建个人学习会话 |

## 未知角色线路

未知或缺失角色时只执行输入安全预检和最小澄清：

```text
请确认当前身份：学生、教师、监护人或教育管理者。
```

在角色确认前，不读取学生记录、不生成正式评分、不创建持续学习状态，也不进入业务子 Skill。

## 路线切换

- 学生切换为教师任务：要求明确说明角色变化，不沿用学生阶段证据。
- 教师进入陪学模式：创建独立学生会话，不把教师工作台状态当作学习者证据。
- 监护人或管理者请求个体数据：重新检查授权，不因之前一次授权永久开放。
- 角色切换不绕过生成前预检、质量审校和最终门禁。
